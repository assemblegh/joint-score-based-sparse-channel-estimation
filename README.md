# 基于扩散模型的大规模 MIMO 联合信道估计与符号检测

# Joint Channel Estimation and Data Detection in Massive MIMO Systems Based on Diffusion Models

> 本仓库实现基于分数生成模型(NCSNv2,退火朗之万动力学)的大规模 MIMO 联合稀疏信道估计与数据检测,参考论文 *Joint channel estimation and data detection in massive MIMO systems based on diffusion models*(Zilberstein et al., arXiv:2311.10311)。
>
> This repository implements joint sparse channel estimation and data detection in massive MIMO systems using a score-based generative model (NCSNv2 with annealed Langevin dynamics), following the paper *Joint channel estimation and data detection in massive MIMO systems based on diffusion models* (Zilberstein et al., arXiv:2311.10311).

---

## 项目简介 | Overview

本仓库在论文官方实现(https://arxiv.org/abs/2311.10311)的基础上进行了本地化修改与扩展:

- **主方法**:将信道矩阵 **H**(NR×NT)视为 2 通道 2D 图像(实部 + 虚部),形状为 `[batch, 2, NR, NT]`;分数网络学习 **H^H**(共轭转置)的先验分数,通过退火朗之万动力学从联合后验 `p(H, x | Y)` 中采样,交替更新信道估计与 QAM 符号检测。

This repository is adapted and extended from the official implementation (https://arxiv.org/abs/2311.10311):

- **Main method**: the channel matrix **H** (NR×NT) is treated as a 2-channel 2D image (real + imaginary), with shape `[batch, 2, NR, NT]`. The score network learns the prior score of **H^H** (conjugate transpose) and samples from the joint posterior `p(H, x | Y)` via annealed Langevin dynamics, alternating between channel estimation and QAM symbol detection.

## 数据 | Data

训练使用由 QuaDriGa 生成器(`quadriga/` 文件夹)生成的 3GPP 信道数据,文件名为 `data/TDL_A_sparse_n.mat`:

- 数据集包含 10000×8×100 的信道样本(8 接收天线 × 100 发射天线),稀疏度为 10%。
- 训练集与验证集在同一个文件中。

将 `.mat` 文件放在主目录下的 `data/` 文件夹即可。

Training uses 3GPP channel data generated by the QuaDriGa simulator (`quadriga/` folder), stored as `data/TDL_A_sparse_n.mat`:

- The dataset consists of 10000×8×100 channel samples (8 receive × 100 transmit antennas) with a sparsity ratio of 10%.
- Training and validation data are in the same file.

Place the `.mat` file in the `data/` folder under the main directory.

## 预训练模型 | Pre-trained Models

3GPP 信道的预训练扩散模型可直接从 [Google Drive](https://drive.google.com/drive/folders/1uHxGHTyU4SXyHYXvPtjnekEKCVNfb24r?usp=sharing) 下载,下载后放在 `models/` 文件夹下,命名为 `model_3gpp_64x32.pt`。

自行训练时,`train_score.py` 会将最终权重自动保存到 `models/` 文件夹下由 sigma 和信道类型构成的路径中(如 `models/sigmaT30.0/final_model_3gpp_64_TDLA_S_n.pt`);`test_score2.py` 默认加载该路径的权重。

A pre-trained diffusion model for 3GPP channels can be downloaded from [Google Drive](https://drive.google.com/drive/folders/1uHxGHTyU4SXyHYXvPtjnekEKCVNfb24r?usp=sharing). Once downloaded, place it in `models/` as `model_3gpp_64x32.pt`.

When training from scratch, `train_score.py` automatically saves the final weights under `models/` in a path constructed from the sigma schedule and channel type (e.g., `models/sigmaT30.0/final_model_3gpp_64_TDLA_S_n.pt`); `test_score2.py` loads the weights from that path by default.

## 训练 | Training

下载示例 3GPP 数据后,运行以下命令训练扩散模型:

After downloading the example 3GPP data, train the diffusion model by running:

```bash
python train_score.py --gpu 0 --train 3GPP
```

- `--train`:信道类型(`3GPP`、`TDL-A`、`CDL-C`、`CDL-D`),决定从 `data/` 加载哪个 `.mat` 文件。
- 模型超参数硬编码在 `train_score.py` 顶部的 `DotMap` 中(天线尺寸 `[8, 100]`、批次大小 32、学习率 1e-4、训练轮数 40、几何 sigma 调度共 2311 个噪声水平、EMA 衰减率 0.999 等),修改脚本即可调整超参数。
- 训练完成后,最终模型权重自动保存至 `models/` 文件夹。

- `--train`: channel type (`3GPP`, `TDL-A`, `CDL-C`, `CDL-D`), which controls which `.mat` file is loaded from `data/`.
- Hyperparameters are hardcoded in the `DotMap` at the top of `train_score.py` (antenna size `[8, 100]`, batch size 32, learning rate 1e-4, 40 epochs, geometric sigma schedule with 2311 noise levels, EMA decay 0.999, etc.). Edit the script to change them.
- The final model weights are automatically saved in the `models/` folder after training.

## 推理 | Inference

### 主方法:基于分数的联合估计与检测 | Main Method: Score-based Joint Estimation and Detection

```bash
python test_score.py --gpu 0 --channel 3GPP
```

`test_score1.py` 与 `test_score2.py` 是其变体,其中 **`test_score2.py` 是最新、注释最完整的版本**(中文注释,支持 TDL-A 稀疏信道,8×100 天线)。三个脚本均加载预训练 NCSNv2 模型,运行退火朗之万动力学,从 H 与 x 的联合后验中采样。

`test_score1.py` and `test_score2.py` are variants; **`test_score2.py` is the most recent and best-documented version** (with Chinese comments and support for TDL-A sparse channels with 8×100 antennas). All three scripts load the pretrained NCSNv2 model and run annealed Langevin dynamics to sample from the joint posterior of H and x.

关键参数 | Key arguments:

| 参数 | 含义 | 默认值 |
| --- | --- | --- |
| `--gpu` | GPU 编号 | 0 |
| `--channel` | 信道类型 | `3GPP` |
| `--pilots_list` | 导频数列表 P | `[30]` |
| `--batch_size_x_list` | 数据符号数列表 D | `[30]` |
| `--pilot_alpha` | 导频 alpha 参数 | `[4.0]` |
| `--noise_boost` | 信道朗之万噪声增强系数 η | `0.001` |
| `--sample_joint` | 是否联合采样(导频+符号) | `True` |
| `--save_channels` | 是否保存信道数据 | `0` |

运行结束后,结果以 `.pt` 文件自动保存(字典包含 `snr_range`、`oracle_log`、`ser_log` 等)至 `results_joint_seed4321/` 或类似目录。

After running, results are automatically saved as `.pt` files (dicts containing `snr_range`, `oracle_log`, `ser_log`, etc.) under `results_joint_seed4321/` or similar directories.

### 运行时配置 | Runtime Configuration

联合朗之万采样的运行时配置位于 `configs/config.yml`(调制阶数 `mod_n=4` 即 QPSK、SNR 范围 15–22.5 dB、H 与 x 的更新步长 `epsilon_H` / `epsilon_x_*`、温度 `temp_*`、每噪声级步数 `steps_per_noise_level=3` 等),由 `utils/util.py` 中的 `dict2namespace()` 加载。注意 H 与 x 的更新使用不同的噪声水平与步长。

The runtime configuration for joint Langevin sampling lives in `configs/config.yml` (modulation order `mod_n=4`, i.e., QPSK; SNR range 15–22.5 dB; step sizes `epsilon_H` / `epsilon_x_*`; temperatures `temp_*`; steps per noise level `steps_per_noise_level=3`, etc.), loaded by `dict2namespace()` in `utils/util.py`. Note that the H and x updates use different noise levels and step sizes.

## 代码架构 | Code Architecture

### 扩散模型 NCSNv2 | Diffusion Model (NCSNv2)

- `ncsnv2/models/ncsnv2.py` — `NCSNv2Deepest`:分数网络(带 InstanceNorm++ 的 U-Net、ELU 激活、几何 sigma 调度),是整个扩散先验的核心。
- `ncsnv2/losses/dsm.py` — 去噪分数匹配损失(`anneal_dsm_score_estimation`)。
- `ncsnv2/models/ema.py` — 模型权重的指数移动平均(EMA)辅助工具。
- `ncsnv2/` 目录改编自 Yang Song 的 NCSNv2 仓库,其原始的 `main.py`、配置文件与图像数据集在本项目中未被使用,仅导入模型定义与损失。

- `ncsnv2/models/ncsnv2.py` — `NCSNv2Deepest`: the score network (U-Net with InstanceNorm++, ELU activations, geometric sigma schedule). This is the core diffusion prior.
- `ncsnv2/losses/dsm.py` — Denoising score matching loss (`anneal_dsm_score_estimation`).
- `ncsnv2/models/ema.py` — Exponential moving average (EMA) helper for model weights.
- The `ncsnv2/` directory is adapted from Yang Song's NCSNv2 repo. Its original `main.py`, config files, and image datasets are unused — only the model definition and loss are imported.

### 信道数据管道 | Channel Data Pipeline

- `data/loaders.py` — `Channels(Dataset)`:加载 `.mat` 信道文件、归一化、生成随机 QPSK 导频、计算含噪观测 `Y = HP + N`,返回 H、H^H、P、Y、特征值等字段。
- `data/sample_generator.py` — `sample_generator`:合成信道生成(i.i.d. 高斯、相关、正交)与 QAM 调制,用于合成实验而非真实 3GPP 数据。
- `sample_generator.py`(根目录)— 与 `data/sample_generator.py` 重复。

- `data/loaders.py` — `Channels(Dataset)`: loads `.mat` channel files, normalizes, generates random QPSK pilots, and computes noisy observations `Y = HP + N`. Returns a dict with H, H^H, P, Y, eigenvalues, etc.
- `data/sample_generator.py` — `sample_generator`: synthetic channel generation (i.i.d. Gaussian, correlated, orthogonal) with QAM modulation. Used for synthetic experiments, not for real 3GPP data.
- `sample_generator.py` (root) — a duplicate of `data/sample_generator.py`.

### MIMO 系统模型辅助 | MIMO System Utilities

- `utils/util.py` — `sym_detection()`、`batch_matvec_mul()`、`gaussian()`(朗之万采样的软 QAM 先验)、配置工具与共享 logger。
- `channel.py` — 独立工具:加载 `.pt` 结果文件并将信道矩阵导出为 `.mat`,供 MATLAB 分析。

- `utils/util.py` — `sym_detection()`, `batch_matvec_mul()`, `gaussian()` (soft QAM prior for Langevin sampling), config utilities, and a shared logger.
- `channel.py` — standalone utility: loads a `.pt` result file and exports channel matrices to `.mat` for MATLAB analysis.
